### Verification install
* Review version of NPM
```bash
npm --version
```
* Review NodeJS version
```bash
node --version
```
* Initialize a new project 
```bash
npm init
```
* run a file
```bash
node [file name]
npm run start
```
* Install packages (Local)
```bash
npm install [package name]
npm i [package name]
```
* Install package (Global)
```bash
npm install -g [package name]
npm i -g [package name]
```
* Install dependency's for developers 
```bash
npm install [package name] -D
```
* Uninstall package
```bash
npm uninstall [package name]
```
* Clean Cache 
```bash
npm cache clean --force
```
* View global modules
```bash
npm list -g --depth=0
```
* Search package
```bash
npm search [package name]
```
* List installed package
```bash
npm list
```
