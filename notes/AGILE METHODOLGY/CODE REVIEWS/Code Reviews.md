Code reviews are when a developer is finished working on an issue, and another developer looks over the code and shares his feedback on the code.
### Points to review
* Are there any obvious logic errors in the code?
* Looking at the requirements, are all cases fully implemented?
* Are the new automated tests enough for the new code?
* Do existing computerized tests need to be rewritten to account for changes in the code?
* Do you know if the new code meets existing style guidelines?
### Feedback
Code review in Agile facilitates knowledge exchange between experienced and new team members, helping to identity problematic areas in the code and ensuring that new ideas are complemented by existing knowledge. This process not only helps detect errors and improve code quality but also fosters a culture of mentoring and collaboration within the team.
